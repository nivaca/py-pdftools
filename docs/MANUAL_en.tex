\section{Introduction}
\noindent
\texttt{py-pdftools} is a program to read and work on PDF documents. It
annotates them, fills their forms, redacts what must not be read, reads the
text of scanned pages (OCR), numbers and arranges their pages, adds headers,
footers and watermarks, imposes them for printing, signs them and checks
their signatures, combines them, makes them smaller, protects them with
passwords and exports their pages, pictures and text. It has a window,
\texttt{py-pdftools-gui}, and a command line, \texttt{py-pdftools}, which
does most of the same work without a window, on one file or on many.

\index{pdf2iso}\index{annotations}\index{annotations!tags}\index{annotations!categories}\index{layers}\index{redaction}\index{ocr@OCR}\index{page labels}\index{headers and footers}\index{watermarks}\index{imposition}\index{pdf/a@PDF/A}\index{pdf/x@PDF/X}%
The program brings together seven earlier programs of mine:
\texttt{py-annotate} (annotations), \texttt{py-redact} (redaction),
\texttt{py-foliation} (page labels, headers, footers and watermarks),
\texttt{py-imposition} (imposition), \texttt{py-pdfocr} (OCR),
\texttt{pdf-word-finder} (the pages of words, for an index) and
\texttt{pdf2iso} (copies as PDF/A and PDF/X). Documents made with them are
read as before: the tags and categories of annotations, the layers of
headers, footers and watermarks, and the history of an imposition kept
their names.

\index{modes}\index{menus!submenus}\index{smaller copies}\index{command line}\index{macos and windows@macOS and Windows}%
This manual explains the window first, mode by mode, then the work on
whole files, the settings and the command line. The menus are written in
italics, with their submenus after a \enquote{>}, as \menu{File\then Save a
copy\then Smaller}; keys are written as \key{Ctrl+S}. On macOS, \key{Ctrl}
is the Command key. The pictures show the window in English; with the
interface in Spanish, every menu and dialog is in Spanish too (see
section~\ref{sec:settings}).

\index{licence}%
\texttt{py-pdftools} is free software, under the GNU General Public
License, version 3 or later. It uses PyMuPDF (GNU AGPL 3), pikepdf (Mozilla
Public License 2.0), reportlab (BSD) and PySide6 (GNU LGPL 3); the full list
of the software it uses, with its licences, is in
\texttt{docs/THIRD-PARTY.md}.

\section{Installing it}
\label{sec:install}

Every version is published on GitHub and on Codeberg (the addresses are on
the first page), with these files:

\index{appimage@AppImage}\index{fedora (copr, rpm)@Fedora (Copr, RPM)}\index{installers}\index{macos and windows@macOS and Windows}%
\begin{itemize}
\item \texttt{py-pdftools-VERSION-x86\_64.AppImage}: the AppImage, for any
  Linux;
\item \texttt{py-pdftools\_VERSION-1\_amd64.deb}: the package for Debian and
  Ubuntu;
\item \texttt{py-pdftools-VERSION-1.fc45.noarch.rpm}: the Fedora package,
  signed, with the key that signs it, \texttt{RPM-GPG-KEY-py-pdftools};
\item \texttt{py-pdftools-VERSION.zip}: the source, with the installers
  for Linux, macOS and Windows;
\item \texttt{py\_pdftools-VERSION-py3-none-any.whl} and
  \texttt{py\_pdftools-VERSION.tar.gz}: the wheel and the source package,
  for Python.
\end{itemize}

\subsection{Fedora}

\index{fedora (copr, rpm)@Fedora (Copr, RPM)}%
The easiest way is the Copr repository, for Fedora 45 and later. It uses
Fedora's own Python, PyMuPDF, pikepdf, reportlab and PySide6, and installs
a menu entry and the manual page (\texttt{man py-pdftools}):

\begin{verbatim}
$ sudo dnf copr enable nivaca/py-pdftools
$ sudo dnf install py-pdftools
\end{verbatim}

\noindent\index{fedora (copr, rpm)@Fedora (Copr, RPM)}\index{pyhanko@pyHanko}\index{tools!hand@Hand}\index{digital signatures}%
Updates then come with \texttt{sudo dnf upgrade}. The RPM of
each release can also be installed by hand, after importing its key with
\texttt{sudo rpm --import RPM-GPG-KEY-py-pdftools}. Fedora does not package
pyHanko, the library of digital signatures, so the RPM goes without it;
\texttt{python3 -m pip install --user pyhanko} installs it in your own
packages, where the program looks for it (the menu \menu{File\then
Security} says so too).

\subsection{Debian and Ubuntu}

\index{debian and ubuntu@Debian and Ubuntu}%
The \texttt{.deb} of each release is for Debian 12, Ubuntu 22.04 and
later. It installs the commands \texttt{py-pdftools} and
\texttt{py-pdftools-gui}, a menu entry and the manual page. Debian has no
Python 3.14 yet, so the package brings its own, with Qt and the libraries
(pyHanko among them), in \texttt{/opt/py-pdftools}, as the AppImage does:

\begin{verbatim}
$ sudo apt install ./py-pdftools_*_amd64.deb
\end{verbatim}

\subsection{The AppImage}

\index{appimage@AppImage}\index{fedora (copr, rpm)@Fedora (Copr, RPM)}\index{pyhanko@pyHanko}\index{command line}%
The AppImage needs nothing else: it brings its own Python, Qt and
libraries, pyHanko among them, and runs on any Linux with glibc 2.34 or
later (Ubuntu 22.04, Debian 12, Fedora 35 and later). Make it executable
and run it; with a command after its name, it works as the command line:

\begin{verbatim}
$ chmod +x py-pdftools-*-x86_64.AppImage
$ ./py-pdftools-*-x86_64.AppImage book.pdf
$ ./py-pdftools-*-x86_64.AppImage impose booklet book.pdf
\end{verbatim}

\subsection{The installers (Linux, macOS, Windows)}

They need Python 3.14 or later. From the folder of the source (the ZIP):

\begin{verbatim}
$ install/install.sh               (Linux, macOS)
$ install/install.sh --uninstall
> install\install.bat              (Windows)
> install\install.bat -Desktop     (with a shortcut)
> install\install.bat -Uninstall
\end{verbatim}

\noindent\index{links}\index{macos and windows@macOS and Windows}%
The first two lines install (or update) and uninstall it on
Linux and macOS, the others on Windows, where \texttt{-Desktop} also puts
a shortcut on the desktop. On Windows the options may also be written as
for \texttt{install.sh} (\texttt{-{}-uninstall}, \texttt{-{}-desktop},
\texttt{-{}-python} followed by the path of a \texttt{python.exe}); a word
that is none of them is reported as an unknown option. Each one makes a Python environment of its own for
\texttt{py-pdftools}, installs it there with its libraries (downloaded from
PyPI, so the first installation needs the internet), links the commands
\texttt{py-pdftools} and \texttt{py-pdftools-gui}, and adds the window to
the menu of the system. Nothing needs administrator rights, and the
settings are never touched, so an update keeps them.

\subsection{From the source}

\index{uv}%
With \texttt{uv}, the program runs straight from a copy of the source:

\begin{verbatim}
$ git clone https://github.com/nivaca/py-pdftools.git
$ cd py-pdftools
$ uv run py-pdftools-gui book.pdf
$ uv run py-pdftools --help
\end{verbatim}

\subsection{What else it can use}

Three programs, installed apart, add what they do; without them,
\texttt{py-pdftools} works without that:

\index{fedora (copr, rpm)@Fedora (Copr, RPM)}\index{tesseract@Tesseract}\index{ghostscript@Ghostscript}\index{verapdf@veraPDF}\index{ocr@OCR}\index{ocr@OCR!languages}\index{pdf/a@PDF/A}\index{pdf/x@PDF/X}\index{language of the interface}%
\begin{itemize}
\item \textbf{Tesseract}, for OCR, with the languages of the documents
  (\texttt{tesseract-langpack-\ldots} on Fedora, \texttt{tesseract-ocr-\ldots}
  on Debian and Ubuntu);
\item \textbf{Ghostscript}, for copies as PDF/A and PDF/X;
\item \textbf{veraPDF}, if it is installed, to check the PDF/A copies.
\end{itemize}

\noindent\index{appimage@AppImage}\index{installers}\index{pyhanko@pyHanko}\index{digital signatures}%
Digital signatures need pyHanko: the AppImage and the installers
bring it; elsewhere, \texttt{pip install 'py-pdftools[signatures]'} adds it.

\section{Starting the program}

The window is opened from the menu of the system, or with
\texttt{py-pdftools-gui}, with or without files:

\begin{verbatim}
$ py-pdftools-gui
$ py-pdftools-gui book.pdf notes.pdf
$ py-pdftools-gui book.pdf#page=12
$ py-pdftools-gui book.pdf#nameddest=intro
\end{verbatim}

\noindent\index{opening at a page or destination}%
With \texttt{\#page=} a document opens at that page, and with
\texttt{\#nameddest=} at a named place of it. If the window is already
open, the files are opened in it instead of in a new one.

\subsection{Keeping it ready, in the background}
\label{sec:background}

\index{background, running in the}%
Starting a program with Qt and PyMuPDF takes a second or two. If
\menu{Settings\then General\then Keep running in the background} is ticked,
closing the last window does not end the program: it stays in memory, with
an icon in the tray of the desktop (where the desktop has one), and a
window ready for the next document, hidden. Running
\texttt{py-pdftools-gui} again, or opening a PDF from the file manager,
then shows that window in a few hundredths of a second. The icon of the
tray opens a window or ends the program; \menu{File\then Quit}
(\key{Ctrl+Q}) ends it too.

\index{background, running in the}\index{session, start with the}%
With \menu{Settings\then General\then Start with the session} the program
also starts when you log in, in the tray and without a window
(\texttt{py-pdftools-gui --background}), so that the first document of the
day opens at once as well.

\section{The window}
\label{sec:window}

\index{modes}\index{toolbars}\index{thumbnails}\index{bookmarks}\index{annotations!status}\index{redaction}\index{ocr@OCR}\index{imposition}%
Figure~\ref{fig:read_en} shows the window with a document open. From the

and here, beside them, the bookmarks; in the middle, the pages; at the

\subsection{The modes}

\index{modes}\index{annotations!grouping and aligning}\index{keys}%
The bar of the modes chooses what the window does, and how it is arranged.
\key{Ctrl+1} to \key{Ctrl+6} choose the modes in the order of the bar.

\index{tesseract@Tesseract}\index{modes!read@Read}\index{modes!ocr@OCR}\index{modes!redact@Redact}\index{modes!annotate@Annotate}\index{modes!foliate@Foliate}\index{modes!impose@Impose}\index{toolbars}\index{thumbnails}\index{zoom}\index{annotations}\index{annotations!stamp}\index{annotations!grouping and aligning}\index{redaction}\index{redaction!redacted copy}\index{ocr@OCR}\index{page labels}\index{headers and footers}\index{watermarks}\index{opening view}\index{imposition}\index{imposition!booklet}%
\begin{description}
\item[Read] only the pages and their thumbnails, with the toolbars to
  open, find, move through the pages and zoom; the mouse moves the pages.
\item[OCR] the text of scanned pages, read by Tesseract
  (section~\ref{sec:ocr}).
\item[Redact] boxes over what must not be read, and the redacted copy
  (section~\ref{sec:redact}).
\item[Annotate] highlights, notes, drawings, stamps and the rest of the
  annotations, with their panel (section~\ref{sec:annotate}).
\item[Foliate] the labels of the pages, their order, headers, footers and
  watermarks, and the view when the document is opened
  (section~\ref{sec:foliate}).
\item[Impose] the pages arranged on sheets for printing: booklets, n-up,
  step and repeat (section~\ref{sec:impose}).
\end{description}

\index{modes}\index{toolbars}\index{thumbnails}\index{annotations!grouping and aligning}\index{page labels!ranges}%
Each mode keeps its own arrangement of the window: which toolbars and
panels are shown, where they are, the size of the thumbnails and the width
of the panels. Arrange a mode once, dragging its toolbars and panels or
hiding them with a right click, and choosing it again brings that
arrangement back, also the next time the program is opened.

\index{modes}\index{hints of the modes}%
\menu{Help\then Tips for this mode} (\key{F1}) shows, over the bottom of
the pages, a hint on what can be done in the mode chosen. With
\menu{Settings\then Appearance\then Show a hint} ticked, the hint is also
shown for a few seconds whenever a mode is chosen; it is off at first. The
tooltips, the small notes on what a button, menu or field does when the
mouse rests on it, are off at first as well, and are turned on in the same
place, with \menu{Show tooltips}. Those of the toolbars show always: every
button, box and field of a toolbar has one, since most buttons have only an
icon.

\index{modes}\index{menus!submenus}\index{zoom}\index{annotations!grouping and aligning}\index{redaction}\index{ocr@OCR}\index{imposition}%
The menus change with the mode too: Redact, Pages, Impose and OCR appear
in their modes, and the menu Tools in Annotate. The menus File, Edit and
View are always there, grouped in submenus (\menu{File\then New},
\menu{Export}, \menu{Import}, \menu{Security}; \menu{View\then Panels},
\menu{Go to}, \menu{Zoom}, \menu{Page layout}).

\subsection{Toolbars}

\index{toolbars}\index{toolbars!locking}\index{toolbars!icons and text}\index{annotations!locking}%
The toolbars can be dragged by their handle to another place, or out of
the window. A right click on any toolbar shows the list of toolbars, to
show or hide them, and how all of them look: icons only, text only, text
beside or under the icons, and the size of the icons. At first they show
small icons only (16 points), the bar of the modes as well; the tip of each
button says its name and its key. The same choices are
in \menu{Settings\then Appearance}, with \menu{Lock the toolbars}, which
keeps them where they are.

\index{toolbars}\index{toolbars!customizing}%
\menu{Settings\then Toolbars\then Customize the toolbars} (figure~\ref{fig:toolbars_en})
chooses the buttons of each toolbar and their order: the actions on the
left are added with the arrow, those on the right taken out or moved up
and down. It can also make new toolbars of one's own, with whatever
actions are wished, delete them, and bring any toolbar back to how it was at first.

\shot{toolbars_en}{0.75}{Customize the toolbars: the buttons of the toolbar
  Navigation.}

\subsection{The thumbnails}

\index{thumbnails}\index{annotations}\index{page labels}%
The panel of the thumbnails (\key{F3}) shows the pages small, each with its
label (see section~\ref{sec:labels}), or its number in the file if it has
none, never both: in figure~\ref{fig:read_en}, the first page is labelled
\enquote{i}, the second \enquote{1}. The box of the page shows it the same
way, and the count beside the box is only how many pages there are. A dot
and a number after the label say how many annotations or boxes the page has. The slider under the
thumbnails changes their size.

\index{thumbnails}\index{copying text}\index{annotations!copying}\index{ocr@OCR}\index{headers and footers}\index{watermarks}%
A click on a thumbnail goes to its page. \key{Ctrl+click} and
\key{Shift+click} choose several, and \key{Ctrl+A}, with the thumbnails in
focus, chooses them all. The pages chosen can be dragged to another place
in the document. Their right click
offers what can be done with them: turn, duplicate, extract or delete them,
move them, insert pages before or after them, number them, put a header or
watermark on them, read their text (OCR), and choose how the document
opens.

\subsection{Opening and saving}

\index{opening!recent documents}\index{opening!a document}\index{tabs}\index{view!split}\index{pages!splitting}%
A document is opened with \menu{File\then Open} (\key{Ctrl+O}), by dropping
it on the window, or from \menu{File\then Open recent}. \menu{File\then Open
in a new tab} (\key{Ctrl+T}) opens it in a tab of the same window; with
\menu{Settings\then General\then Open documents in tabs of one window},
every document opens so. \menu{View\then Split the view}
(\key{Ctrl+\textbackslash}) puts the tab shown beside the others, to read
two documents side by side, and \menu{View\then Move the tab to a window of
its own} takes it out.

\index{passwords}\index{zoom}%
A document protected with a password asks for it when it is opened. A
document changed by another program while it is open is opened again by
itself (this can be turned off in \menu{Settings\then General}), and each
document opens where it was left, at the same page and zoom (in
\menu{Settings\then Documents}).

\index{modes}\index{saving}\index{working copy}\index{annotations}\index{forms}\index{redaction}\index{redaction!boxes}\index{imposition}%
\menu{File\then Save} (\key{Ctrl+S}) writes the changes into the document:
its annotations, its redaction boxes (as the redaction marks of PDF, not
yet applied), the form, and the changes of the modes Foliate and Impose.
Those changes are made at once on a working copy, and shown, but the file
stays as it was until it is saved. Saving keeps the signatures of a signed
document valid for what they signed. \menu{File\then Save as}
(\key{Ctrl+Shift+S}) writes a copy and goes on with it.

\index{modes}\index{undo and redo}\index{annotations}\index{page labels}\index{imposition}%
\menu{Edit\then Undo} (\key{Ctrl+Z}) and \menu{Redo} (\key{Ctrl+Shift+Z})
go back and forth through everything done to the document, in any mode:
annotations, boxes, labels, pages moved or deleted, an imposition applied.

\index{recovery copy}%
While the document is changed and not yet saved, the program keeps a
recovery copy of it every two minutes (the time is set in
\menu{Settings\then General}). If the program ends without saving, the next
time the document is opened it offers to bring those changes back.

\subsection{The rest of the menu File}

\index{passwords}\index{flattening}\index{combining files}\index{pdf from pictures@PDF from pictures}\index{smaller copies}\index{pdf version@PDF version}\index{pdf/a@PDF/A}\index{pdf/x@PDF/X}%
Besides opening and saving, the menu File holds the work on whole files,
which is explained in section~\ref{sec:files}: \menu{New} (combining files,
a PDF from pictures), \menu{Save a copy} (flattened, smaller, with another
PDF version, PDF/A and PDF/X\ldots), \menu{Export}, \menu{Import} and
\menu{Security} (passwords and signatures). It also has:

\index{comparing versions}\index{annotations}%
\begin{description}
\item[Compare with another version] marks on this document what differs
  from another version of the same text (another edition, a draft): its
  words, in reading order.
\item[PDF properties] shows what the document is: its title, author,
  subject, keywords and dates, the program that made it, its file (name,
  folder, size, PDF version, whether it is linearized for fast web view),
  its contents (pages, page size, whether it is tagged, has a form, layers,
  attached files, signatures, bookmarks), its encryption and what it
  doesn't allow; and, in a second tab, the fonts it uses, with their type,
  their encoding, whether they are embedded (whole or a subset) and the
  pages they are used on. \menu{Copy} puts all of it on the clipboard.
\item[Print] (\key{Ctrl+P}) prints the pages with their annotations.
\item[Close window] (\key{Ctrl+W}) and \textup{\textit{Quit}}
  (\key{Ctrl+Q}).
\end{description}

\section{Reading and moving through a document}
\label{sec:reading}

\index{modes}%
These ways of reading and moving work in every mode.

\subsection{Moving}

\index{moving through pages}\index{page labels}%
The pages are shown one under the other, and scroll with the wheel of the
mouse, the scroll bar or the keys. \key{PgUp} and \key{PgDown} go to the
previous and next page, and so do \key{Left} and \key{Right} in the view
of the pages, while the pages fit across it (zoomed in wider, they scroll
sideways; with annotations selected, they move them); \key{Ctrl+Home} and \key{Ctrl+End} to the first and
the last. The same is done with the toolbar \menu{Page navigation}, at the
top, between \menu{Navigation} and \menu{Zoom}: First page, Previous page, a box with the page shown
and how many there are (\enquote{12 of 180}), Next page and Last page. Like
the other toolbars, it can be moved, hidden or changed in \menu{Customize
the toolbars}, where its box can also be put on any other toolbar. The
toolbar \menu{Navigation}, at the top, goes back and forth through the
places jumped to, and has the tools Select text, Hand and Zoom to area. The
toolbar \menu{Zoom box}, at the top on the right, has the box of the zoom;
like any toolbar, it can be dragged elsewhere (to the bottom, to a side,
out of the window) or hidden with a right click on the toolbars. The box of
the page takes a page number or a label: type \enquote{12}, or
\enquote{xiv}, and press Enter; over \enquote{of 180}, a tip gives the
size and orientation of the page.

\index{tools!hand@Hand}\index{autoscroll}%
The tool Hand (\key{M}) moves the pages by dragging them; holding the space
bar turns any tool into Hand for a moment, and the middle button of the
mouse scrolls by itself, faster the farther the mouse goes.

\index{links}\index{history of views}\index{bookmarks}\index{copying text}%
Links are followed with a click (with the tool Select, with
\key{Ctrl+click}), and web and mail addresses written in the text too,
after asking whether to open them (in \menu{Settings\then Documents}).
\key{Alt+Left} and \key{Alt+Right} go back and forth through the places
jumped to: links, bookmarks, pages typed, places found.

\subsection{Bookmarks}

\index{bookmarks}\index{annotations!filtering}\index{page labels}%
\menu{View\then Panels\then Bookmarks} (\key{F5}) shows the bookmarks of
the document (its outline) as a tree, with the label of the page each one
goes to (figure~\ref{fig:read_en}). The box at the top filters them by a
word, and the buttons below open or close the whole tree. A click goes to
the bookmark's place. Their right click adds a bookmark at the place shown,
renames, deletes, moves and indents them, gives them a colour, bold or
italics, and can make them from the headings of the text.

The panel is hidden each time the program starts, and opening a document
doesn't show it, even when the document asks for its bookmarks to be
shown: only \key{F5} or the menu opens it. Once open, it stays in every
mode until it is closed, except Impose, which shows no pages (there
\key{F5} is \menu{Preview}); it comes back on leaving Impose.

\subsection{Finding text}

\index{modes}\index{modes!redact@Redact}\index{toolbars}\index{finding!and redacting}\index{finding!text}\index{annotations!highlight}\index{redaction}%
The button Find of the main toolbar (\key{Ctrl+F}) opens \menu{Find and
highlight}: it finds a word, a phrase or a pattern in the document, lists
the places found with their context, and goes to each one with
\menu{Previous} and \menu{Next}; it can also mark them (see
section~\ref{sec:findmark}). In the mode Redact, the same button opens
\menu{Find and redact}, which puts boxes over them (see
section~\ref{sec:redact}).

\index{finding!quick find}%
Beside that button is the quick find box, \menu{Find in the text}
(\key{Ctrl+Shift+F} puts the cursor in it). It looks for what is typed in
it without minding capitals or accents: \key{Enter} goes to the next place
found, from the page shown, and \key{Shift+Enter} to the previous one,
going round at the end; beside the box, \texttt{3/17} says which place is
shown, of how many. It marks nothing: each place is only shown for a
moment. \key{Esc} goes back to the pages.

\subsection{Selecting and copying text}

\index{modes}\index{tools!hand@Hand}\index{selecting text}\index{copying text}\index{annotations!highlight}\index{annotations!underline, strikeout}\index{redaction}%
The tool Select text (\key{X}), beside Hand in every mode, selects text as
in a text editor: drag over it (across pages too), \key{Alt+drag} for a
column, double-click a word, triple-click a line, \key{Shift+click} to
extend the selection. \key{Ctrl+C} copies it, and \key{Ctrl+A} selects the
text of the page. Its right click offers to highlight, underline or strike
it out, to mark it for redaction, or to find it.

\subsection{Zoom and layout}

\index{zoom}\index{zoom!inked area}\index{zoom!actual size}\index{tools!zoom to area@Zoom to area}%
The box of the zoom, on the toolbar Zoom box, takes a percentage, or offers the
usual ones. \menu{View\then Zoom} fits the page (\key{Ctrl+0}), the width
(\key{Ctrl+9}), the height (\key{Ctrl+8}), or the inked area of the page
(\key{Ctrl+7}), that is, its text and pictures without their margins, as
wide as the window. \menu{Actual size} (\key{Ctrl+Shift+0}) shows the page
at its printed size on the screen. \key{Ctrl++} and \key{Ctrl+-} zoom in and
out, as does \key{Ctrl} with the wheel, in a short animation; with the
wheel, the place under the pointer stays under it. The tool Zoom to area (\key{Z})
zooms to a frame dragged on a page, or zooms in where it clicks.

\index{modes}\index{modes!foliate@Foliate}\index{page layout!two pages}\index{page layout!cover}\index{page layout!gaps}\index{view!rotating}%
\menu{View\then Page layout} shows the pages one at a time, instead of
scrolling, or two side by side (\key{Ctrl+Shift+2}), as an open book; with
\menu{The first page alone, as a cover}, the even pages are on the left
(figure~\ref{fig:view_en}). Unticking \menu{Gaps between the pages} makes
them one long sheet. \menu{Rotate the view} (\key{Ctrl+]} and \key{Ctrl+[})
turns every page in the window, but not in the file; to turn pages for
good, use the mode Foliate.

  the reading colours White on black.}

\subsection{Reading colours and full screen}

\index{reading colours}%
\menu{View\then Reading colours} shows the pages in other colours, which
tire the eyes less at night: white, yellow or green on black, light on
dark grey, or colours of one's own. Only the pages in view change, not the
file; pictures change with them.

\index{full screen}%
\menu{View\then Full screen} (\key{F11}) shows the pages one at a time,
full screen, as a presentation: the arrows or a click turn them, and
\key{Esc} ends it.

\subsection{Sharper text}

\index{sharpness of text}%
MuPDF, which draws the pages, draws the edges of letters soft, without
snapping them to the pixels of the screen as the fonts of the desktop are,
so that text can look a little blurred beside them. \menu{Settings\then
Appearance\then Text on the pages} sets how they are drawn: \menu{As drawn}
(as MuPDF draws them), \menu{Sharper} (the default) or \menu{Sharpest},
which darken those edges and then make them steeper with a sharpening
filter (an unsharp mask), light in Sharper and stronger in Sharpest. The
difference shows most when the pages are zoomed out, where a letter is only
a few pixels tall. Pictures get a little darker and sharper too.

\subsection{Colours}

\index{colours of annotations}\index{page labels!ranges}%
The colours offered in the menus each have a meaning, shown beside their
name, so that a reading can be marked consistently: yellow for what is
important, green for definitions and concepts, blue for references and
citations, pink for questions, orange for arguments and conclusions, purple
for context and history, red for errors to check. \menu{Settings\then
Colours} changes the colours and what each means to you: each colour is
shown as a patch of it, its name in the tip, beside the field of its
meaning; a click on it offers the others.

\subsection{The panel of the annotations}

\index{annotations}\index{annotations!panel}\index{annotations!filtering}\index{annotations!sorting}\index{annotations!status}\index{annotations!tags}\index{annotations!categories}%
The panel of the annotations (\key{F4}) lists every annotation of the
document, with its page, kind, author, status, the date it was changed, and
its text (what it marks, or what it says). Its box at the top searches their
text, and the lists below filter them by kind, author, colour, status, tag
and category; the list on the right sorts them by page, by kind, by author,
by status, or the last changed first. With \menu{View\then Annotations\then Only those the list shows},
the pages show only the annotations the filters let through;
\menu{Show the annotations} (\key{Ctrl+Shift+A}) hides them all, to see the
document as it is.

\index{annotations}\index{annotations!note}\index{annotations!replies}\index{annotations!status}\index{annotations!tags}%
A click on an annotation of the list goes to it and selects it.
\key{Alt+Down} and \key{Alt+Up} go to the next and previous one. Under the
list, the annotation selected can be given a colour, a comment, tags, and a
status (accepted, rejected, cancelled, completed); replies can be written
to it, as in a conversation, and are kept in the document as the replies of
PDF, which other programs show. \key{C} writes the comment of the
annotation selected, or adds a note if none is.

\subsection{Properties}

\index{annotations}\index{annotations!tags}\index{annotations!categories}\index{annotations!properties}\index{annotations!locking}%
\menu{Edit\then Properties} (\key{Alt+Return}), or a double click, shows
all the properties of the annotations selected (figure~\ref{fig:annot_props_en}):
their colours, border, font, alignment and opacity, their text, author,
tags and categories, and whether they are locked (a locked annotation
can't be moved, resized, erased or deleted). With several selected, what is
changed changes in all of them. \menu{Use this style for new annotations of
this kind} makes the tool give that look to the next ones.

\shot{annot_props_en}{0.45}{The properties of a text box.}

\index{annotations}\index{textual criticism}\index{annotations!exporting}%
The part \menu{Textual criticism} is for editors of texts: it makes the
annotation an entry of the critical apparatus, with its kind (a variant
reading, a manuscript reading, an emendation, a conjecture, a lacuna, a
scribal correction, a marginal addition\ldots), the reading of the text and
the other reading, the witness (a manuscript or edition, by its siglum),
its location, its source, the rationale and the confidence. \menu{File\then
Export\then The annotations\then The critical apparatus} writes those
entries in the order of the text.

\index{annotations}\index{annotations!categories}%
The categories an annotation may be put in are set in
\menu{Settings\then Categories}, one on each line.

\subsection{Editing several annotations}

\index{annotations}\index{annotations!grouping and aligning}\index{annotations!copying}\index{page labels!ranges}%
\menu{Edit\then Copy}, \menu{Paste} and \menu{Duplicate} (\key{Ctrl+D})

Select} selects those of the page (\key{Ctrl+A}) or those of the same kind,
and \key{Esc} selects none. \menu{Edit\then Arrange} groups them
(\key{Ctrl+G}), so that they are selected, moved and deleted together, and
ungroups them (\key{Ctrl+Shift+G}); locks them; and aligns them (left
sides, centres, tops\ldots), spreads them evenly or makes them the same
size. \menu{Edit\then Remove annotations} deletes those of the page, or all.

\subsection{Find and highlight}
\label{sec:findmark}

\index{finding!and highlighting}\index{wildcards}\index{annotations}\index{annotations!highlight}\index{annotations!underline, strikeout}%
\menu{Tools\then Find and highlight} (\key{Ctrl+F}, figure~\ref{fig:find_highlight_en})
finds a word, a phrase or a pattern on the pages and marks the places
found, with a highlight, an underline, a strikeout or any other text
annotation. It can match case and whole words only, use a regular
expression, ignore accents, take \enquote{u} for \enquote{v} and
\enquote{i} for \enquote{j} (as in Latin texts), and use wildcards
(\texttt{*} for any letters, \texttt{?} for one: \texttt{iust*}
finds \textit{iustitia}, \textit{iustus}, \textit{iusto}). It finds on all pages,
on the page shown or on some; the places found are listed with their
context, and they are marked all at once, or only those chosen.

\subsection{Exporting and importing annotations}

\index{annotations}\index{annotations!exporting}\index{exporting}%
\menu{File\then Export\then The annotations} writes the annotations:

\index{annotations}\index{annotations!replies}\index{annotations!tags}\index{annotations!categories}\index{textual criticism}\index{annotations!exporting}\index{exporting!text}%
\begin{itemize}
\item as a report, in Markdown, page by page, with what they mark and their
  comments;
\item as a table (CSV), for a spreadsheet;
\item as the critical apparatus (Markdown);
\item as data (JSON), to import them again, in this program or in
  \texttt{py-annotate};
\item as XFDF, the format in which PDF programs exchange annotations (tags
  and categories are this program's own, and are left out);
\item as a summary of the comments (PDF): each page with annotations,

  and their replies.

\menu{File\then Import\then Annotations} reads them from a JSON
or XFDF file, or from another copy of the same PDF, such as one annotated by
someone else; the annotations already in the document are not added twice.

\index{links}\index{annotations}\index{flattening}\index{forms}%
\menu{File\then Save a copy\then Flattened} makes the annotations part of
the pages: they are seen and printed everywhere, but can't be edited or
removed any more. \menu{Without annotations} saves the document without
any (links and form fields stay).

Each mode works on its own annotations. In Annotate, the redaction boxes
are shown, but the mouse goes through them; in Redact, the annotations are
shown, and the mouse goes through them. The menu Layers, in Annotate, shows
and hides the layers of a document that has them (its optional content).

A document with a form opens the panel Form (\key{F6}) by itself, or it

What most forms ask is done without JavaScript: numbers, dates, phone

\section{Redacting}
\label{sec:redact}

\index{modes}\index{modes!redact@Redact}\index{redaction}\index{redaction!redacted copy}%
Redacting removes for good what must not be read: names, numbers,
addresses, passages, pictures. In the mode Redact (figure~\ref{fig:redact_en}),
boxes are put over what is to be removed; nothing is removed until the

\subsection{Marking}

\index{modes}\index{redaction}\index{redaction!marking}%
The tool Redact (\key{R} in this mode) marks text by dragging over it: a box
is made over each of its lines. Elsewhere, or with \key{Ctrl}, it draws a
box, over a picture or any area. A double click marks only a word, or a
picture.

\index{annotations!stamp}\index{redaction}\index{redaction!boxes}%
The panel of the boxes, on the right, lists them, with their page, the

\subsection{Find and redact}

\menu{Redact\then Find and redact} (figure~\ref{fig:redact_find_en}) finds

e-mail addresses, phone numbers, credit card numbers, dates, identity

match case, whole words, or a regular expression, on all pages, on this

with their context; \menu{Mark them all} puts a box over each, and

A document may look redacted and not be: a black box drawn over a name, or

\menu{Redact\then Find text only covered} looks for such text, and lists

\subsection{The redacted copy}

\index{bookmarks}\index{annotations}\index{redaction}\index{redaction!redacted copy}%
\menu{Redact\then Save the redacted copy} (\key{Ctrl+Shift+R}) writes a
copy of the document in which what is under the boxes is removed: text,
pictures (the part under the box), drawings and annotations. The copy is
checked as it is written: if any text under a box can still be read, or a
bookmark gives it away, the program says so. The copy is made from the
document as it was last saved, so the program offers to save the other

\menu{Save the redacted copy as} makes it a PDF/A or PDF/X
(section~\ref{sec:pdfa}). With \menu{Also remove metadata, hidden text,

holds besides its pages: its title, author and other metadata, text that
isn't shown, layers switched off, attached files, JavaScript and links.
\menu{Redact\then Metadata} (\key{Ctrl+Shift+M}) shows and changes the
metadata the copy will have, or removes it.

Copies that make the annotations part of the pages (flattened, searchable,

\menu{Redact\then Remove hidden information} shows what the document holds
besides what its pages show (figure~\ref{fig:hidden_en}): metadata,
attached files, bookmarks, page labels, comments, form fields, hidden
text, layers switched off, links and scripts, thumbnails, and deleted or
unused content. A copy is saved without what is ticked; the document open
is not changed, and its boxes are not applied.

\shot{hidden_en}{0.55}{Remove hidden information.}

\index{links}\index{layers}\index{redaction}\index{metadata}\index{sanitizing}\index{redaction!settings}%
\menu{Redact\then Sanitize the document} saves at once a copy without

with nothing else changed. \menu{Settings of redaction} sets the colour of new boxes, what
happens to the pictures and drawings under a box (only the part covered is
removed, or the whole picture, or nothing), and how the boxes not yet
applied are shown (their outline and the opacity of their fill). Text
under a box is always removed.

\section{Reading scanned pages (OCR)}
\label{sec:ocr}

\index{tesseract@Tesseract}\index{modes}\index{modes!ocr@OCR}\index{undo and redo}\index{redaction}\index{ocr@OCR}%
A scanned page is a picture: its text can't be found, selected or marked.
The mode OCR (figure~\ref{fig:ocr_en}) reads that text with Tesseract and
writes it into the document, invisible, under the picture of each page, so
that it can be found, copied, highlighted and redacted like any other. It
is a change of the document, undone and saved like the others.

\shot{ocr_en}{1}{The mode OCR, with a scanned page.}

\index{tesseract@Tesseract}\index{thumbnails}\index{ocr@OCR!languages}\index{ocr@OCR!turning pages}\index{language of the interface}%
The panel says which version of Tesseract is installed and how many pages
are scans without text. It reads those pages, those chosen in the
thumbnails, the page shown, or a list of pages; pages that already have
text are left as they are. The languages are ticked in its list, the main
one first; reading in the right languages matters a great deal for the
result. \menu{Turn the pages lying sideways or upside down} turns them
first (this needs the data \enquote{osd} of Tesseract). \menu{Recognise
text} (\key{Ctrl+Shift+O}) reads them.

\index{tesseract@Tesseract}\index{ocr@OCR!doubtful words}%
With \menu{Check the doubtful words before the text is written}, the words
Tesseract was not sure of are shown, each beside its picture, to be
corrected before the text is written; how sure is sure enough is set in
\menu{Doubtful below}.

\subsection{Page labels}
\label{sec:labels}

\index{thumbnails}\index{page labels}\index{page labels!styles}%
The page labels are the numbers a PDF viewer shows for its pages, instead
of 1, 2, 3: a book's front matter in roman numerals, its text from 1, an

\section{A word index}
\label{sec:wordindex}
\index{word index}\index{page labels}\index{command line}%
\menu{Edit\then Word index} (figure~\ref{fig:word_index_en}), also a
button on the toolbar \menu{Find}, comes from my
program \texttt{pdf-word-finder}. It finds the words, phrases or patterns of
a list, and gives the pages where each appears: not their place in the
file, but their labels, the numbers printed on them, which are what a reader
needs to open the book (section~\ref{sec:labels}). The result, by default,
is one line for each term, ready to be copied into the index of a book:

\begin{verbatim}
amor i, 1, 4
Sharahzad 3, 5, 23, 34
Nombre de Dios 5, 23
\end{verbatim}

\shot{word_index_en}{0.85}{The word index of three terms, the third a
  regular expression, with the page in the file where it differs from the
  label.}

\index{word index!terms}\index{regular expressions}%
The terms are written on the left, one on each line, or read from a text
file with \menu{Read a list}; a \texttt{\#} begins a comment, which is left
out. A term is a regular expression if it begins with \texttt{re:} (as
\texttt{re:virtu(s|tem|tis)}), or all of them are, with \menu{Every term is
a regular expression}. A phrase is found even when it is split across two
lines.

\index{word index!options}%
Before the search, the text of the pages is made ready: ligatures are
undone (\enquote{ﬁ} becomes \enquote{fi}), and the words split by a hyphen
at the end of a line are joined again (\menu{Join the words split at the end
of a line}, ticked at first). The other options:

\begin{description}
\item[Whole words only] ticked at first; unticked, \enquote{amor} is found
  in \enquote{amoris} too.
\item[Match case] \enquote{Amor} is not \enquote{amor}.
\item[Ignore accents] \enquote{philologia} finds \enquote{philología}.
\item[Regular expressions, too, as whole words] a regular expression is
  left as it is written, unless this is ticked.
\item[Also the page in the file] where it differs from the label, in
  brackets: \enquote{xiv [seq.~16]}.
\item[In alphabetical order] the terms in the order of the Spanish
  alphabet, which serves English too (accents and capitals left aside, ñ
  after n); otherwise, in the order they were written.
\item[Detailed] how many times each term appears, and its pages one on
  each line; \menu{With context} adds, under each page, a fragment of text
  around each place, of so many characters on each side.
\end{description}

\noindent Above the result, a line says how many terms were found, how
many times, on how many pages; and, apart, what is worth knowing: that the
document has no page labels (then the pages are given by their place in
the file), that some pages have no text (scanned, and not yet read with
OCR: see section~\ref{sec:ocr}), and which terms were not found. A double
click on a page of the result goes to it. \menu{Copy} puts the result on
the clipboard; \menu{Save as text} writes the list, always in alphabetical
order; \menu{Save as CSV} writes a row for each term and page, with how
many times and the context.

The search is made on the document as it is in the window, with its labels
as the mode Foliate shows them, saved or not. From the command line, the
same is done by \texttt{py-pdftools find-words} (section~\ref{sec:cli}).

\section{Imposing}
\label{sec:impose}

\index{modes}\index{modes!impose@Impose}\index{annotations!grouping and aligning}\index{page labels!ranges}\index{imposition}\index{imposition!booklet}\index{imposition!binding, paper, marks}%
Imposing arranges the pages of a document on the sheets of paper they will
be printed on: a booklet, folded in the middle; several pages on each
sheet (n-up); copies of a page repeated to fill a sheet (step and repeat);

\shot{impose_en}{1}{The mode Impose: a 2-up booklet, and a sheet of the

action: click the key of an action and press the new one. \menu{Categories}

the three has a button to bring back the usual ones.

\subsection{Performance}

\shot{settings_performance_en}{0.6}{Settings, Performance.}

\index{thumbnails}\index{settings!performance}%
\begin{description}
\item[Memory] how much memory the window may use: Low, Normal, High, or All
  pages, which keeps every page and thumbnail drawn, within half of the free
  memory. The more memory, the faster the pages come back.
\item[Transparency effects] selections drawn with transparency; without,
  as outlines, which is faster on old computers.
\item[Smooth the text, Smooth the graphics] antialiasing; without it, the
  pages are drawn faster but rougher.
\item[Animate zooming and scrolling with the wheel] the zoom grows or
  shrinks in a few frames instead of jumping, and the sharp picture of the
  pages comes when it stops; a turn of the wheel glides as far as it
  scrolled at once (a touchpad already scrolls smoothly, and is left as it
  is). On at first; smoother still with the graphics card.
\item[Draw the pages with the graphics card (OpenGL)] scrolling and
  zooming are smoother: the pictures of the pages are moved and scaled by
  the graphics card instead of the processor. Turning PDF pages into
  pictures is still done by the processor, so a page that takes a moment
  to appear takes it all the same. Off at first; it changes the next time
  the program starts. Where OpenGL doesn't work (some virtual machines and
  remote displays), the pages are drawn as usual, and \menu{Check the
  configuration} says why; if the pages show black or flicker, turn it
  off.
\end{description}

\subsection{Where the settings are kept}
\label{sec:files-kept}

\index{modes}\index{toolbars}\index{tools!hand@Hand}\index{annotations!grouping and aligning}\index{page labels!ranges}\index{headers and footers!variables}\index{configuration files}\index{macos and windows@macOS and Windows}%
The settings are kept in a file, \texttt{config.toml}, in the configuration
folder: \texttt{\textasciitilde/.config/py-pdftools/} on Linux,
\texttt{\textasciitilde/Library/Application Support/py-pdftools/} on macOS,
\texttt{\%APPDATA\%\textbackslash py-pdftools\textbackslash} on Windows, or
the folder named by the environment variable \texttt{PY\_PDFTOOLS\_CONFIG}.
Each setting is checked when it is read, so a file edited by hand can't
stop the program: a value that can't be read is replaced by its default.
The certificates of the signers trusted are kept in the same folder, in
\texttt{trusted}. How each mode arranges the window, the toolbars and the
documents open at the end are kept apart, in \texttt{py-pdftools.conf},
in the same configuration folder on Linux.

\index{language of the interface}%
The language of the interface can also be chosen with
\texttt{py-pdftools interface es} (or \texttt{en}).

\section{The command line}
\label{sec:cli}

\index{passwords}\index{forms}\index{pdf/a@PDF/A}\index{pdf/x@PDF/X}\index{command line}\index{command line!common options}%
\texttt{py-pdftools} does without a window most of what the window does,
on one file or on many, so that it can be used in scripts.
\texttt{py-pdftools COMMAND -h} explains each command and all its options.
The commands that change PDFs write a new file
(\texttt{-o OUTPUT}), change the files themselves (\texttt{-i}), or write
them in a folder (\texttt{--output-dir}); \texttt{-n} shows what would be
done, without writing anything; \texttt{--conform} saves them as PDF/A or
PDF/X; \texttt{--password} opens protected files.

\index{pdf2iso}\index{forms}\index{ocr@OCR}\index{page labels}\index{pages!splitting}\index{headers and footers}\index{bates numbering@Bates numbering}\index{watermarks}\index{imposition}\index{combining files}\index{smaller copies}\index{exporting!pages as pictures}\index{pdf version@PDF version}\index{pdf/a@PDF/A}\index{pdf/x@PDF/X}\index{language of the interface}\index{command line!completion}%
\begin{longtable}{@{}lp{0.68\textwidth}@{}}
\toprule
Command & What it does\\
\midrule
\endhead
\texttt{labels} & shows, sets, clears or copies the page labels\\
\texttt{view} & shows or sets how PDFs open in a viewer\\
\texttt{header-footer} & adds headers and footers, with Bates numbers\\
\texttt{watermark} & adds watermarks\\
\texttt{pages} & moves, deletes, rotates, inserts or splits pages\\
\texttt{impose} & imposes pages for printing (with its own commands)\\
\texttt{pdf2iso} & converts PDFs to PDF/A or PDF/X-4\\
\texttt{ocr} & reads the text of scanned pages\\
\texttt{combine} & combines PDFs, or some of their pages\\
\texttt{from-images} & makes a PDF of pictures\\
\texttt{export} & exports the pages as pictures, the pictures, or the text\\
\texttt{pdf-version} & shows the PDF version of files, or saves a copy with another\\
\texttt{form} & shows, fills, tabulates and flattens forms\\
\texttt{reduce} & makes a smaller copy\\
\texttt{find-words} & the (labelled) pages of words, phrases or patterns: an index\\
\texttt{completion} & prints the completion script of a shell\\
\texttt{interface} & shows or chooses the language of the interface\\
\bottomrule
\end{longtable}

\noindent Some examples:

\begin{verbatim}
$ py-pdftools labels book.pdf
$ py-pdftools labels set book.pdf 1:r 9:D -i
$ py-pdftools header-footer book.pdf \
      --footer-center 'Page $pagelabel' -i
$ py-pdftools watermark book.pdf --text DRAFT --opacity 30% -i
$ py-pdftools pages book.pdf --move 201-214 9 --delete LAST -i
$ py-pdftools pages book.pdf --split-bookmarks 1 --output-dir parts
$ py-pdftools view book.pdf --layout cover --open-at 9 -i
$ py-pdftools impose booklet book.pdf -o booklet.pdf
$ py-pdftools ocr scan.pdf -l lat+spa --rotate --report
$ py-pdftools combine a.pdf b.pdf:2-5 -o all.pdf
$ py-pdftools from-images *.jpg -o scans.pdf --paper A4
$ py-pdftools export text book.pdf -o book.md
$ py-pdftools form fill form.pdf data.json -o filled.pdf
$ py-pdftools reduce scans.pdf -o smaller.pdf --level medium
$ py-pdftools find-words book.pdf amor "re:virtu(s|tem|tis)" \
      --words-file names.txt --sort --txt index.txt
\end{verbatim}

\noindent\index{page labels}%
The second sets the labels i, ii\ldots\ from page 1 and 1,
2\ldots\ from page 9. In \texttt{pages}, the operations are made in the
order given, each on the pages as the ones before left them; a list of
pages is written as \texttt{9-20,31}, with \texttt{LAST} counting from the
end, or \texttt{all}, \texttt{even}, \texttt{odd}. The single quotes keep
the shell from reading \texttt{\$pagelabel}.

\index{command line!completion}%
\texttt{py-pdftools completion bash} (or \texttt{fish}, \texttt{zsh})
prints a script that completes the commands and options in the shell.

\section{When something goes wrong}

\index{appimage@AppImage}\index{tesseract@Tesseract}\index{ghostscript@Ghostscript}\index{pyhanko@pyHanko}\index{modes}\index{toolbars}\index{toolbars!customizing}\index{toolbars!icons and text}\index{thumbnails}\index{recovery copy}\index{sharpness of text}\index{annotations!grouping and aligning}\index{forms}\index{redaction}\index{redaction!text only covered}\index{redaction!redacted copy}\index{ocr@OCR}\index{ocr@OCR!languages}\index{ocr@OCR!models}\index{smaller copies}\index{pdf/a@PDF/A}\index{pdf/x@PDF/X}\index{language of the interface}\index{configuration files}%
\begin{description}
\item[The text looks blurred] choose \menu{Sharper} or \menu{Sharpest} in
  \menu{Settings\then Appearance\then Text on the pages}, and check that
  \menu{Smooth the text} is ticked in \menu{Performance}.
\item[A big document is slow] give the window more memory in
  \menu{Settings\then Performance}, or make the thumbnails smaller.
\item[OCR is not offered, or reads badly] install Tesseract with the
  languages of the document, tick them in the panel, the main one first,
  and download the more accurate models in \menu{OCR\then Languages}.
\item[PDF/A or PDF/X can't be made] install Ghostscript.
\item[The signatures are not in the menu] install pyHanko
  (\texttt{pip install 'py-pdftools[signatures]'}; with the RPM,
  \texttt{python3 -m pip install --user pyhanko}), or use the AppImage.
\item[The redacted copy warns that text can still be read] some text under
  a box was not removed (it may be in a form that can't be parsed): look at
  the pages named, and put a box over the whole area, or use \menu{Find
  text only covered}.
\item[The program ended without saving] open the document again: it
  offers to recover the changes kept in its recovery copy.
\item[A setting is wrong] delete \texttt{config.toml}
  (section~\ref{sec:files-kept}); the program starts with its defaults.
\item[The toolbars or panels are lost] show them again with a right click
  on the toolbars, or put a toolbar back with \menu{As it was at first} in
  \menu{Customize the toolbars}; deleting \texttt{py-pdftools.conf}
  brings back the first arrangement of every mode.
\end{description}
